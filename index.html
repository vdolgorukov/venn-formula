Формула по диаграмме Венна

Щёлкните по областям диаграммы, чтобы закрасить их. Справа появятся равносильные выражения для закрашенной части.

 

Области (конституенты)

Имена:

Варианты по порядку: самая короткая формула по числу вхождений букв (полный перебор); если включена разность, сначала с ней, потом без неё. Затем «структурная» запись: из множества, построенного только с помощью ∪ и ∩, вычитается другое такое же, из него третье и т. д. (например, объединение попарных пересечений минус пересечение всех трёх); без разности вычитание записывается через пересечение с дополнением. Дальше минимальная ДНФ, минимальная КНФ и объединение конституент. Совпадающие варианты не повторяются, скобки при смешанных операциях ставятся всегда. Для четырёх множеств перебор занимает несколько секунд после первого переключения.
